DIGITAL FORENSICS LAB

Kali Linux Image Forensics Lab

AUTHORIZED FORENSICS TOOLKIT

Educational command reference for analyzing images you own or are authorized to examine. These commands inspect files and metadata; they do not prove authenticity by themselves.

LAB / OFFLINE
forensics@kali:~ · DIGITAL FORENSICS LAB
# Select an image you own
exiftool image.jpg
sha256sum image.jpg
file image.jpg
identify image.jpg

# Extract embedded metadata
exiftool -a -u -g1 image.jpg

# Inspect JPEG structure
jpeginfo -c image.jpg

# Look for embedded strings
strings -n 8 image.jpg | head -50

# Compare two files by cryptographic hash
sha256sum image-a.jpg image-b.jpg

# Metadata removal (make a copy first)
exiftool -all= -o cleaned.jpg image.jpg
⌁ LIVE COMMAND MACHINEsimulated shell — runs in your browser, no real system is touched
forensics@kali:~$ help
Type a command above or tap a chip. Try: exiftool image.jpg, sha256sum image.jpg, file image.jpg
If you've scanned an image in the Digital Forensics Lab below, real file data will be used here.
forensics@kali:~$
EXIF / Metadata

exiftool can reveal camera model, timestamps, GPS fields and other embedded metadata when present.

Hash Verification

sha256sum creates a fingerprint for comparing whether two files are byte-for-byte identical.

File Structure

file, identify and jpeginfo help inspect file type, dimensions and JPEG integrity.

Authenticity ≠ Metadata

Missing or changed EXIF does not automatically mean “fake”. Provenance, source history and specialist analysis are needed for stronger conclusions.
